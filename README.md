# ToDo List — практическая работа №2

Консольное Java-приложение для управления списком задач. Задачи хранятся в JSON-файле и загружаются при следующем запуске.

## Данные студента

- ФИО: **укажите своё ФИО**
- Группа: **укажите свою группу**
- Уровень выполнения: **оценка 5**

## Возможности

- Просмотр списка задач.
- Добавление, редактирование и удаление задач.
- Автоматическое сохранение после изменения списка.
- Загрузка сохранённых задач при старте.
- JSON-файл с отступами для удобного чтения.
- Проверка некорректного пункта меню, номера задачи, пустого или слишком длинного названия.
- Понятное сообщение при повреждённом JSON-файле; исходный файл не перезаписывается автоматически.
- Уникальные номера задач, сохраняющиеся при удалении и перезапуске.

## Требования

- Java 17 или новее
- Maven 3.8 или новее

## Запуск

В корне проекта выполните:

```bash
mvn clean test
mvn exec:java
```

Также можно собрать исполняемый JAR и запустить его:

```bash
mvn clean package
java -jar target/todo-list-1.0.0.jar
```

По умолчанию данные сохраняются в `data/tasks.json` относительно текущей папки запуска. Можно указать другой путь первым аргументом:

```bash
java -jar target/todo-list-1.0.0.jar C:/path/to/tasks.json
```

## Меню

```text
1. Показать задачи
2. Добавить задачу
3. Редактировать задачу
4. Удалить задачу
0. Выход
```

Изменения сохраняются автоматически. JSON-файл создаётся после добавления первой задачи.
